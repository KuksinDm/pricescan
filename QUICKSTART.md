## 🚀 Запуск проекта

### 1. Создайте .env файл
```bash
cp .env.example .env
# Отредактируйте .env файл
```

### 2. Запустите все сервисы
```bash
# Разработка
./deploy.sh dev

# Или продакшен
./deploy.sh prod
```

### 3. Проверьте работу
- API: http://localhost:9040/api/
- Swagger: http://localhost:9040/api/docs/
- Admin: http://localhost:9040/admin/

## 📊 Мониторинг

### Включите мониторинг (опционально)
```bash
# В .env файле
PROMETHEUS_ENABLED=true
GRAFANA_ENABLED=true

# Запустите с мониторингом
docker-compose --profile monitoring up -d
```

- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000 (admin/admin)

## 🧪 Тестирование

```bash
# Запуск тестов
docker-compose exec web_pricescan python manage.py test

# С покрытием
docker-compose exec web_pricescan python -m pytest --cov=.
```

## 📈 Производительность

- **Ежедневно в 02:00** - полный парсинг

### Метрики

- Количество запросов

- Состояние сервисов

## 🔧 Настройка

### Алерты
```python
# Создание алерта через API
POST /api/alerts/
{
    "product": 1,
    "threshold_price": "1000.00",
    "currency": "RUB",
    "alert_type": "price_drop"
}
```

### Мониторинг
```python
# Обновление метрики
POST /api/monitoring/metrics/update_value/
{
    "name": "custom_metric",
    "value": 150.0,
    "labels": {"service": "parser"}
}
```

## 🛡️ Безопасность

- **Rate limiting**: 100 запросов/час для анонимных, 1000 для авторизованных
- **CORS**: настроен для localhost
- **JWT токены**: 30 минут access, 7 дней refresh
- **HTTPS**: готов к настройке в продакшене
