## 🎯 О проекте

PriceScan — это современная система для отслеживания цен на настольные игры, построенная с использованием микросервисной архитектуры. Проект демонстрирует навыки работы с современным Python стеком, контейнеризацией и интеграцией различных технологий.

### ✨ Ключевые особенности

- 🔄 **Автоматический парсинг** — мониторинг цен в реальном времени
- 🤖 **Telegram бот** — удобные уведомления и управление
- 📊 **Аналитика цен** — история изменений и тренды
- 🏗️ **Микросервисы** — масштабируемая архитектура
- 🔒 **Безопасность** — JWT аутентификация и сервисные токены

## 🛠️ Технологии и навыки

### Backend & API
- **Django 5.2** + **Django REST Framework** — основной API
- **PostgreSQL** — основная база данных
- **Redis** — кэширование и брокер сообщений
- **Celery** — асинхронная обработка задач
- **JWT Authentication** — безопасная аутентификация

### Парсинг и автоматизация
- **BeautifulSoup** — парсинг статических сайтов
- **Playwright** — автоматизация браузера для сложных сайтов
- **aiohttp** — асинхронные HTTP запросы
- **Pydantic** — валидация данных

### Bot & Frontend
- **aiogram 3.x** — современный Telegram бот фреймворк
- **FastAPI** — внутренний API для бота
- **Dependency Injection** — чистая архитектура

### DevOps & Инфраструктура
- **Docker & Docker Compose** — контейнеризация
- **Nginx** — reverse proxy
- **UV** — современный менеджер зависимостей Python
- **Health Checks** — мониторинг состояния сервисов

## 🏗️ Архитектура

Проект построен по микросервисной архитектуре и состоит из следующих компонентов:

### 🔧 Основные сервисы

- **`pricescan_api`** — Django REST API с PostgreSQL
- **`pricescan_bot`** — Telegram бот на aiogram 3.x
- **`pricescan_parser`** — Парсер на BeautifulSoup для статических сайтов
- **`pricescan_playwright`** — Парсер на Playwright для динамических сайтов
- **`nginx`** — Reverse proxy и статические файлы

### 🗄️ Инфраструктура

- **PostgreSQL** — основная база данных
- **Redis** — брокер сообщений для Celery
- **Celery** — асинхронная обработка задач
- **Celery Beat** — планировщик задач

## 🚀 Быстрый старт

### Предварительные требования

- Docker и Docker Compose
- Python 3.12+

### Запуск через Docker

1. **Клонирование репозитория**
```bash
git clone <repository-url>
cd pricescan
```

2. **Настройка переменных окружения**
```bash
cp .env.example .env
# Отредактируйте .env файл с вашими настройками
```

3. **Запуск всех сервисов**
```bash
docker-compose up -d
```

4. **Выполнение миграций**
```bash
docker-compose exec web_pricescan python manage.py migrate
```

5. **Создание суперпользователя**
```bash
docker-compose exec web_pricescan python manage.py createsuperuser
```

### Доступ к сервисам

- **API**: http://localhost:9040/api/
- **API Documentation**: http://localhost:9040/api/docs/
- **Admin Panel**: http://localhost:9040/admin/

## 🛠️ Разработка

### Локальная разработка

1. **Установка зависимостей**
```bash
cd pricescan_api
uv sync
```

2. **Настройка базы данных**
```bash
# Используйте SQLite для разработки
python manage.py migrate
python manage.py loaddata initial_data.json
```

3. **Запуск сервисов**
```bash
# API сервер
python manage.py runserver

# Celery worker
celery -A config worker --loglevel=info

# Celery beat
celery -A config beat --loglevel=info
```

### Тестирование

```bash
# Запуск тестов
python manage.py test

# Проверка покрытия
coverage run --source='.' manage.py test
coverage report
```
